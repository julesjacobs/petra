# Bounded original-input result validation

`benchmark_smpt_classic.py --native-original --bounded-validation` moves post-run translation/witness/certificate validation into a separate child. Defaults: `--validation-seconds 30 --validation-memory-mib 2048 --validation-response-mib 1`. The child checks all canonical translations one branch at a time, frees each branch before loading the next, and retains the existing independent-proof acceptance rule. Solver timing and instruction resources remain untouched; separate `validation` wall/resource fields describe the checker. Checker timeout/memory/process failure yields unknown; rejected/malformed proofs yield error. The original solver artifacts remain available when no definitive result can be accepted.

Validation responses and metadata have size limits. Linux adds an address-space cap; portable process-tree RSS sampling and the deadline bound the checker on other supported hosts. RLIMIT_FSIZE bounds checker output. These limits do not bound solver-generated logs/artifacts themselves; that remains a separate future improvement. Validation source and configuration are recorded in the run snapshot/environment. The legacy in-parent path remains the default for reproduction; stress runs should explicitly enable bounded validation.

Startup input hashing now streams 1MiB chunks and deduplicates shared resolved paths. It rejects inconsistent hashes or file identity changes and rechecks validated input identities before invocations. It neither parses full nets nor retains their bytes. Hashing remains outside solver timing and has no separate time deadline. It assumes inputs are immutable; identity metadata is a change detector, not a defense against adversarial timestamp-restoring edits.

Failed collection slots remain unsupported rows for every method/repetition, with explicit `execution_attempted=false`, `failure_stage=collection`, collection status/observation and property-slot metadata. They have no fabricated solver resources. The environment/report includes planned/imported/unsupported/unobserved counts. Imported slots continue through the existing dispatch. This is an imported-subset comparison whenever collection failures exist; original-input competitor availability has not been separated from canonical import availability.

Validation: 34 tests passed in `research/bounded-validation-tests.log`, including the original native frontend suite unchanged and the bounded variant, malformed witness/certificate handling, AG polarity, empty/disjunctive targets, canonical mismatch, validator timeout/OOM attribution, hash deduplication/mutation rejection and missing-file failure slots. No stress solver measurements or remote changes were performed by this work.
